# UI 设计规则（新增功能必须遵守）

> **2026-10-22 更新**：多页壳已被否决。常驻左栏、页面级第二套导航不再采用。
> 上位文件是 [principles.md](principles.md)（App 级十条原则）。本文件是迁移期沉淀的 UI 细则，
> 与原则冲突时以原则为准。

本文件是**规范**，不是建议。新增页面、模块、动作前先对照；不符合的要么改，要么在 PR/提交说明里写清例外理由。
设计令牌与组件类见 [design-system.md](design-system.md)。

## 一、导航

**R1 一级入口预算**
- 移动端底部 tab **最多 4 个**：控制台、文件、会话、更多。
- 桌面左栏可见项 ≤7；超出进"更多"。
- 新增一级 tab 必须同时删掉一个，或在评审中说明为什么现有分类不够。

**R2 新功能落点决策树**
1. 是"对某个文件/目录的操作"？→ 动作表（R4），不进导航。
2. 是"聚合/筛选出来的一批文件"？→ 虚拟位置（R9），进文件页侧栏。
3. 是"一种新的会话/长连接"？→ 会话中心的分段（R14），不新增 tab。
4. 是"低频工具/设置"？→ 更多。
5. 以上都不是，且每天会用？→ 才考虑一级 tab（按 R1 预算）。

**R3 会话中心**
- 本地终端与 SSH 是**两个独立页面与状态**，只在"会话"入口下并列；不得合并逻辑或共用会话列表。
- 深链 `/terminal`、`/ssh` 必须一直可用。

**R4 最近任务**
- 顶栏「最近」是跨模块切换器；新模块若产生"正在进行的任务"，必须调用 `Common.pushRecent()` 登记。
- 卡片至少包含标题、类型、跳转地址；v1 不要求实时预览。

## 二、布局与滚动

**R5 一个屏幕一个滚动主人**
- 桌面：页面本身不滚动（`overflow:hidden`），各面板内部滚动。
- 移动：页面只滚到主内容顶部；长列表（进程、窗口、文件、会话）必须自带 `max-height` 与内部滚动。
- 任何列表都不得把页面撑长到需要整页滚动。

**R6 断点**
- `≤640px` 手机；`641–1023px` 平板；`≥1024px` 桌面。
- 行为差异（长按/悬停/虚拟键）用 `(hover: none) and (pointer: coarse)` 判断，不用宽度。
- 新页面必须同时检查三档，至少手机 + 桌面截图。

**R7 头部**
- 每页一个标题 + 最多两个主操作；其余收进"更多"或分段。
- 移动端页面标题与全局顶栏之间不留双层大标题。

## 三、动作

**R8 动作分组与顺序**
固定四组，顺序不可变：
1. 打开类：预览、打开方式、在终端中打开、**问 AI**
2. 传送类：下载、复制、移动、复制路径
3. 管理类：重命名、属性、压缩/解压
4. 危险类：删除（回收站）
- 桌面右键菜单与移动 bottom sheet 必须同序；危险动作红色、置底、二次确认。
- 类型专属动作（解压/运行/编辑）插在所属组内，不新开组。

**R9 虚拟位置**
- 收件箱、最近、收藏等聚合视图是文件页的**侧栏位置**，不是独立 tab。
- 虚拟位置复用同一套行模型与动作表；只允许增加"来源/定位原文件"这类上下文动作。
- 旧路由保留 301 到新位置。

**R10 手势语义**
| 手势 | 行为 |
|---|---|
| 单击文件 | 预览（可预览）/ 打开动作面板（不可预览） |
| 单击文件夹 | 进入 |
| 长按 | 进多选并选中；已选中项长按 = 动作面板 |
| 多选单击 | 切换选中 |
| 空白长按 | 当前目录菜单 |
- 长按触发后必须吞掉随后的合成 click；阈值 500ms；移动超过 10px 取消。
- 不引入双击、三指、边缘滑动等隐藏手势。

**R11 触控尺寸**
- 可点区域 ≥44×44 CSS px；相邻动作间距 ≥8px。
- 不允许只有 hover 才能出现的操作。

**R12 批量安全**
- 重命名、属性、打开方式只对单选出现。
- 批量动作必须对每个对象都成立；"在终端中打开"多选时只允许单目录或退化为当前目录。
- 删除、移动、覆盖类操作必须二次确认，并写事件流。

**R13 问 AI 是一等动作**
- 任何可选文件/文件夹的地方（文件页、收件箱、未来搜索/最近）都必须提供"问 AI"。
- 多选传全部；文件夹递归复制；发起后进入现有 AI 任务面板，不另造流程。

## 四、弹层与反馈

**R14 弹层形态**
- 手机：动作/选择/表单用 bottom sheet；确认类可用小弹窗。
- 桌面：动作菜单用上下文菜单，表单用居中弹窗。
- 同一功能不得手机用整页、桌面用弹窗（除非内容确实需要整页）。

**R15 状态与反馈**
- 操作中：按钮禁用 + 文案变化；不允许无反馈。
- 成功：toast（2–3 秒）；失败：就地错误 + toast，禁止 `alert()`。
- 空状态必须说明"为什么空"和"下一步能做什么"。

**R16 状态记忆**
- 文件页记住上次目录/视图/排序；收件箱记住筛选；终端/SSH 从服务端恢复会话。
- localStorage 键统一 `wp.<domain>.<name>`，读写集中到 `common.js`。

## 五、命名与视觉

**R17 命名**
- 一级：控制台、文件、会话、更多。
- 动作：问 AI（不写"交给AI/发送给AI"混用）、在终端中打开、移入回收站。
- 页面标题与 tab 名称一致；英文只用 SSH、AI 这类通用缩写。

**R18 视觉**
- 只使用 `tokens.css` 的变量；不写死颜色/间距（临时调试除外）。
- 页面级样式放独立 CSS 文件；共享组件样式放 `app.css`。
- 图标只从 `icons.js` 取，不引入第二套图标库。

**R19 可访问性**
- 图标按钮必须有 `title`/`aria-label`；表单有 `label`。
- 桌面支持键盘：Tab 可达、Enter 触发、Esc 关闭弹层。
- 颜色对比度不低于 4.5:1（正文）。

## 六、工程与验收

**R20 共享优先**
- 文件动作、动作面板、确认弹层、空状态、格式化函数放共享模块（`common.js` / `file-actions.js`）。
- 新页面不得复制粘贴另一页的动作表；发现重复先抽取再开发。

**R21 API 与状态**
- 新接口按 `/api/<domain>/<action>`；虚拟位置用 `loc` 参数，不新开路由。
- 会增长的数据写状态目录；写入走 `state.atomicWriteJson` / `appendJsonl`。
- 新配置项必须有默认值，写进 `config.example.json` 与文档。

**R22 测试门槛**
- 新增页面/大改：`tests/smoke.py` 通过 + ego 桌面/移动截图 + 无 console 错误。
- 纯逻辑：补 `tests/test_pure.py`；协议改动：`WP_RUN_PROTOCOL=1` 通过。
- 发布：`deploy.ps1` 冒烟通过；会话相关改动确认守护进程重启范围。

## 七、新模块接入清单（复制到任务里逐项打勾）

- [ ] 入口：一级 tab / 更多 / 虚拟位置 / 动作（按 R2 选择并写明理由）
- [ ] 路由与旧链接兼容（301 或保留）
- [ ] 移动端：390px 无横向滚动、触控 ≥44px、长按/单击语义符合 R10
- [ ] 桌面端：页面不滚、面板内滚、右键菜单顺序符合 R8
- [ ] 动作表：单/多/文件夹/虚拟位置四列都检查（R8/R12）
- [ ] 状态记忆键名 `wp.*`；会话从服务端恢复
- [ ] 共享组件：没有复制粘贴动作表/格式化函数
- [ ] 错误、空状态、加载态齐全（R15）
- [ ] 文档：`docs/` 对应页面 + 本规则有例外则注明
- [ ] 测试：smoke + 纯函数 + ego 截图（R22）

## 八、评审快问

1. 这个功能在手机上从打开到完成，需要几次点击？能不能一步？
2. 它属于"文件动作/虚拟位置/会话/更多"中的哪一类？为什么不是？
3. 列表会不会把页面撑长？滚动条归谁？
4. 多选时哪些动作不该出现？危险动作怎么确认？
5. 半年后加第 8 个模块，导航还放得下吗？
